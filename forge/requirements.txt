# Layer 1 (offline Windows ingestion) — heavy OCR + document-engineering deps.
#
# Target runtime: Python 3.12 on the Windows 11 build machine
#                 (Ryzen 9 7900X, 12 cores / 32 GB RAM).
#
#   pip install -r forge/requirements.txt
#
# SYSTEM PREREQUISITES (not pip-installable):
#   * Tesseract OCR 5.x binary on PATH  -> used by `pytesseract`.
#       Windows: winget install Chocobo.TesseractOCR   (or the UB-Mannheim installer)
#     If the binary is missing, forge/ocr_consensus.py degrades gracefully:
#     Tesseract returns an empty token list and consensus runs on the other 2 engines.
#   * `easyocr` requires a PyTorch build. On this CPU-only box install the CPU wheel:
#       pip install torch --index-url https://download.pytorch.org/whl/cpu
# =============================================================================

# --- PDF rasterization / geometry (normalized-page renderer) -----------------

fastembed>=0.3                # float32 embeddings for semantic search (local model)
